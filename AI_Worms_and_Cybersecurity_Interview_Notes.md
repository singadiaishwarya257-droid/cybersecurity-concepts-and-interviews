## 1. Concepts Learned

### 1.1 AI Worms

An **AI worm** is a potential type of malicious program that may use AI capabilities to automate parts of a cyberattack. Like other worms, it may exploit software vulnerabilities to spread between vulnerable systems.

**Potential risks include:**

- Spreading malware between vulnerable devices
- Compromising systems and data
- Disrupting network services

### 1.2 Computer Virus vs. Computer Worm

| Computer virus | Computer worm |
|---|---|
| Typically attaches itself to a file or program. | Does not need to attach itself to another file. |
| Usually spreads when infected content is executed or shared. | Can replicate and spread independently between vulnerable systems. |
| Often relies on user actions to spread. | Can spread across networks by exploiting vulnerabilities. |

**Key difference:** A virus typically needs a host file or program, while a worm can spread independently.

### 1.3 Cybersecurity

**Cybersecurity** is the practice of protecting computers, devices, networks, and data from cyberattacks.

### 1.4 Important Technical Terms

| Term | Definition |
|---|---|
| **Malware** | Software designed to harm or misuse a system. |
| **Vulnerability** | A weakness in software or a system that an attacker could exploit. |
| **Authentication** | Verifying the identity of a user or device. |
| **Network security** | Protecting networks and connected systems. |
| **Patch** | A software update that fixes a bug or security weakness. |

## 2. Interview Preparation

### Q1. What is an AI worm, how does it spread, and how can we prevent it?

**Sample answer:**

An AI worm is malicious software that may use AI to automate certain cyberattacks. Like other worms, it can exploit software vulnerabilities to spread between vulnerable devices or systems.

We can reduce this risk by updating software regularly, fixing vulnerabilities, using strong authentication, monitoring network activity, and isolating infected devices.

**Key points to cover:**

- Definition of an AI worm
- How software vulnerabilities can enable its spread
- Potential risks to devices and systems
- Preventive security measures

### Q2. What is the difference between a virus and a worm?

**Sample answer:**

A computer virus is malicious software that attaches itself to a file or program. It usually spreads when someone runs or shares the infected file.

A computer worm can copy itself and spread to other vulnerable devices, often through a network, without needing to attach itself to a file.

**Interview takeaway:** A virus typically needs a host file or program, while a worm can spread independently.

## 3. Cybersecurity Prevention Methods

1. **Regular software updates:** Install security patches to fix known vulnerabilities.
2. **Strong authentication:** Use strong, unique passwords and multi-factor authentication.
3. **Network monitoring:** Identify unusual connections and suspicious activity.
4. **Network segmentation:** Separate network systems to limit the spread of attacks.
5. **Device isolation:** Isolate infected or compromised devices to prevent further spread.

## 4. Practical Security Scenario

**Scenario:** A vulnerable computer becomes infected with a worm, and the worm attempts to spread to other devices on the same network.

**Possible response:**

1. Isolate the affected computer.
2. Identify and patch the exploited vulnerability.
3. Check other devices for signs of compromise.
4. Monitor network activity for suspicious connections.
5. Restore affected systems safely and strengthen security controls.
